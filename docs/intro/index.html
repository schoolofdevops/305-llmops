Ultimate LLMOps Bootcamp

Production LLMOps with Kubernetes, vLLM, RAG, evals, observability and AI gateways — on an 8 GB laptop. — by Gourav Shah, School of DevOps & AI.

The complete ops lifecycle for GenAI systems: genuine LLM internals (prefill/decode, KV cache, tokenization, quantization), a real RAG application, LoRA/QLoRA fine-tuning, OCI-standard model packaging, production serving on Kubernetes with vLLM, observability, autoscaling, GitOps, an AI gateway with eval gates and guardrails, and an agentic capstone. Every core lab runs on an 8 GB laptop (16 GB comfort path, cloud/recorded frontier path); no GPU required.

Who this is for​

Engineers across the org moving into GenAI — DevOps, platform, and SRE folks, and just as much application and backend developers who will build on these systems. You should be fluent with containers, Compose, and basic Kubernetes (Deployments, Services, kubectl); no ML or data-science background is assumed — the course builds all the model theory it uses, starting from everyday examples (what happens when you type into ChatGPT) before applying it to the production project.

How to use this course​

Each module ships a Lesson (concepts, analogies, a whiteboard deck and often an interactive simulator), a Lab (copy-runnable, validated live on a real machine), a Deep Dive (the advanced part 2), and a Quiz. Work the modules in order — one project, OpsMate, an SRE/runbook assistant for a fictional company, matures across all thirteen: local model → RAG assistant → fine-tuned model → signed OCI artifact → served on Kubernetes → observed and autoscaled → gateway-fronted and eval-gated → agentic. The lab stack grows the same way: one compose file hand-authored service by service (M1–M7), then Kubernetes manifests grown module by module (M8–M13), ending in a capstone that runs the whole lifecycle end to end.

Start with Prerequisites, then Environment — do not begin Module 1 until every probe passes.
